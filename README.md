Ember Pact is a roguelike deck-builder card game: forge a deck from four elemental suits, climb three acts of branching map nodes, beat an elite for relics, rest or shop between fights, and break the Ember Queen's crown. Every enemy telegraphs its next move, so each hand is a decision you can read and counter.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — keyboard and mouse, desktop browser, no network requests.
